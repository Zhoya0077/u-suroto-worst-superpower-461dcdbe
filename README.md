# Worst Superpower

One line inventing the most useless superpower imaginable: the power to stop time, but only for the exact instant you sneeze — a moment already gone before you could do anything with it.

> I can stop time, but only for the exact instant I sneeze.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

`main.ts` gates the entry first (1–140 characters, single line, not only whitespace, UTF-8 byte size in bounds), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads it back to confirm the file is byte-identical to the gated entry.
